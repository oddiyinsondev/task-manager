# 🚀 Task Manager Pro

Zamonaviy va sodda Task Manager ilovasi: ko‘p rasmlar (Ctrl+V), Word va Excel hujjatlari hamda Telegram bot orqali avtomatlashtirilgan hisobotlar tizimi.

---

## 🌟 Asosiy imkoniyatlar

### 1. 👑 Glass Pro (Task beruvchi):
- Yangi tasklar qo‘shish (Sarlavha, tavsif, sana, vaqt).
- **Rasmlar** yuklash yoki to‘g‘ridan-to‘g‘ri **Ctrl + V** orqali skrinshot tashlash.
- **Hujjatlar yuklash** (Word `.docx`, Excel `.xlsx`, PDF va boshqalar).
- Yangi task qo‘shilganda dasturchiga avtomatik Telegram orqali xabar boradi.
- Bajarilgan ishlar hisoboti va yuklangan natija fayllarini ko‘rish hamda yuklab olish.
- Tasklarni boshqarish va to‘liq nazorat qilish.

### 2. 💻 Dasturchi (Ijrochi):
- Glass Pro bergan vazifalarni sanama-san (Bugun, Ertaga, Kelgusi kunlar) ko‘rish.
- Biriktirilgan topshiriq rasmlari va Word/Excel fayllarini bir marta bosish bilan yuklab olish.
- Vazifani bajargandan so‘ng **"Hisobot yuklash & Bajardim"** tugmasini bosish.
- Bajarilgan ishlar bo‘yicha tavsif, natija skrinshotlari (Ctrl+V) va hisobot fayllarini (Word, Excel) ilova qilish.
- Hisobot topshirilganda Glass Pro ga Telegram bot orqali avtomatik to‘liq hisobot boradi.

---

## 🛠 Texnologiyalar

- **Frontend:** React 19, TypeScript, Vite
- **Dizayn:** Tailwind CSS (Modern Dark Mode)
- **Ikonkalar:** Lucide Icons
- **Animatsiyalar:** Canvas Confetti
- **Integratsiya:** Telegram Bot API (Avtomatlashtirilgan xabarnomalar)
- **Deployment:** Vercel Ready
